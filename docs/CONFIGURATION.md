# 自行填写配置

## 模型接口

- 深度求索：打开“接口设置”，填写自己的 DeepSeek 文字 Key、豆包视觉 Key；云语音另外填写语音 Key。照片识别需要视觉模型权限，不能仅凭文字 Key 使用。实际模型名称应以自己账号当前开通的模型为准。
- 希沃课堂助教：打开模型配置，填写自己的 DeepSeek Key、豆包/生图 Key、语音 Key。配置机制与原客户端一致。
- `examples/` 仅用于解释字段。优先使用界面保存，不要将填好后的 JSON 提交仓库。

独立客户端使用当前 Windows 用户 DPAPI 保存密钥；希沃端沿用原有 connection.json 保存机制，该文件包含敏感信息，应由当前用户保管，不应上传、发截图或复制进交付包。开源整理没有改变这些持久化机制。

## 自建手机服务和公式服务

希沃助教“手机控制”中填写自己部署的 HTTPS 根地址。可选的 `classroom-deployment.json` 只能包含自己的 ServerUrl；公开构建默认不打包该文件。

复杂公式服务由环境变量 `CLASSROOM_SERVICE_URL` 指定，必须是 HTTPS 根地址，例如自行设置为自己的服务器根地址后重新启动应用。服务路由为 POST /api/formula。不配置时不会联系作者原服务。

## 更新服务

默认没有更新源，不会连接作者自用更新服务器。

- `CLASSROOM_UPDATE_SERVER_URL`：自己的 HTTPS 更新服务根地址。
- `CLASSROOM_UPDATE_PUBLIC_KEY_PATH`：自己的 RSA XML 公钥文件绝对路径。

更新清单仍须使用对应私钥签名，并通过现有 SHA256、大小、路径及验签检查。不配置公钥或验签失败时拒绝更新。私钥只应保留在发布端，不能放进仓库或客户端；本仓库不包含任何签名私钥。
